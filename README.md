# EPS95 Pension Calculation Tool

## GitHub Pages deployment (important)

1. Extract this ZIP file on your computer.
2. Open your GitHub repository.
3. Upload **the files inside this folder**, not the ZIP itself.
4. Ensure `index.html`, `app.js`, `styles.css`, `.nojekyll`, and `404.html` are directly in the repository root.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait for the Pages deployment to finish, then open the URL shown under Settings → Pages.

Your website URL is normally:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

Do not open the repository URL as the website URL. Do not upload the ZIP as a single file.

If you use a `docs` folder instead, place all five website files inside `docs` and select `/docs` in GitHub Pages.
